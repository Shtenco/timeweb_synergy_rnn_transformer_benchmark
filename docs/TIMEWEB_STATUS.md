# Статус публикации

**Исследование №06:** GRU и Transformer на одинаковом бюджете.

Направление входит в исходный перечень 12 предложенных и предварительно рассмотренных концепций; публикация требует отдельной приёмки.

- Наличие репозитория в GitHub не означает согласование редакцией.
- Перед передачей текста нужно сверить таблицы с первичными измерениями, ссылки, права на иллюстрации, условия оригинальности, тексты и актуальные правила Хабра.
- Подготовленные ИИ тексты — рабочие материалы для самостоятельной авторской переработки; рукописи не публикуются в открытом репозитории без отдельного решения автора.
- Никакие прогнозы +50/+100 не гарантируют результат публикации: прежняя OOS-оценка для +100 недостаточна для уверенного прогноза.
