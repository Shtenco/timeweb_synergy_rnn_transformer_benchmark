# timeweb_synergy_rnn_transformer_benchmark

## SYNERGY / HIAI — исследование №06: GRU против Transformer

**Статус:** исследовательский прототип, для окончательного вывода требуется независимая верификация. Название Timeweb — идентификатор серии, а не подтверждение одобрения компании.

### Цель и предмет

UCI HAR, равный бюджет CPU. Эксперимент отделяет проверяемую гипотезу от результатов конкретного запуска. Проверяются корректность вычислений, время работы, стоимость, неопределенность результатов и ограничения методики.

### Что лежит в исходном комплекте

- `prototypes/real_experiments/article06_har_sequences.py` — основной измерительный скрипт или сценарий.
- `prototypes/runner.py` — CLI для серии сценариев №01–15.
- `results/` — сохраненные JSON/CSV, графики или протоколы (для тем, где реально проводились прогоны).
- `article/РУКОПИСЬ.md` — редакционная версия, `article/HTML_ДЛЯ_ХАБРА.html` — формат для редактора.
- `SOURCE_MANIFEST.json` — контрольные суммы оригинальных исходных файлов.

**Синхронизация:** перечень относится к подготовленному офлайн-комплекту HIAI. Перед запуском проверьте, что файлы опубликованы в GitHub; эта версия README не удостоверяет полноту загрузки кода.

### Требования и воспроизведение

Python 3.10+, Git, virtualenv, NumPy, scikit-learn, PyTorch CPU, Numba, SciPy, pytest (только по необходимости для соответствующего скрипта). Для №07 также нужен компилятор C++17.

```bash
git clone https://github.com/Shtenco/timeweb_synergy_rnn_transformer_benchmark.git
cd timeweb_synergy_rnn_transformer_benchmark
python -m venv .venv
# Linux: source .venv/bin/activate
# Windows: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m prototypes run 06 --seed 42 --out results/local
```

Для полной репликации нужно запускать реальный измерительный файл `prototypes/real_experiments/article06_har_sequences.py`, сравнивать с исходными результатами, сохранять библиотечные версии и характеристики оборудования. У отдельных тестов могут требоваться локальные исходные датасеты.

### Научная корректность

**Что проверено:** UCI HAR, равный бюджет CPU.

**Чего нельзя утверждать:** Обобщение на другие архитектуры и датасеты не доказано. Приведенные ранее записи в результатах не являются новыми замерами CI; сначала требуется повторный прогон и проверка совпадения.

Протокол: фиксировать seed, dataset/split, версии библиотек, CPU/OS, число повторов, каждое сырое время и checksum при вычислениях. Не выкидывать неудачные прогоны без фиксации причины. Сравнивать конфигурации при равном бюджете, публиковать отрицательные результаты, доверительные интервалы и влияние параметров.

### Редакторская подготовка Timeweb Cloud

Материалу необходимы самостоятельный воспроизводимый эксперимент, честный заголовок, 2–4 абзаца введения, иллюстрации с источниками, рабочие примеры кода, итог и подтверждённые ссылки. Черновик должен быть согласован, авторские права и требования площадки проверены. Упоминание Timeweb Cloud не означает официального партнёрства.
